# مواصفات المنتج — «حِصّة» (Hessa)

**الوعد**: «فلوسك مضبوطة، وطلابك مش بيضيعوا، والباب بيخلص في دقايق — حتى لو النت قاطع.»

## 1) الأدوار والصلاحيات
| الدور | يقدر يعمل إيه |
|---|---|
| صاحب السنتر | كل حاجة: القاعات، المدرسين، التسويات، الخزنة، التقارير المالية |
| المدرس | طلابه ومجموعاته، الامتحانات، الدرجات، الرسايل، تقريره المالي بس |
| المساعد (الأسيستنت) | الحضور، رصد الدرجات، التصحيح بالكاميرا، المتابعة — **من غير ما يشوف الفلوس** |
| السكرتارية | الباب (حضور + تحصيل + إيصال)، تسجيل طالب جديد، إقفال الخزنة — **مفيش حذف ولا تعديل** على أي عملية مالية بعد تسجيلها |
| ولي الأمر / الطالب | بوابة للقراية بس عن طريق لينك سري — من غير تطبيق ولا كلمة سر |

## 2) النواة الإلزامية
1. **الطلاب**: كود قصير لكل طالب + QR للكارت، الصف (ابتدائي/إعدادي/ثانوي عام/بكالوريا + المسار/أزهري)، أخوات، إعفاءات، وموافقة ولي الأمر على البيانات.
2. **المجموعات والجدولة**: مجموعة = مدرس + مادة + صف + مواعيد + قاعة + سعة. **البرنامج بيمنع تعارض القاعة والمدرس تلقائيًا**. نقل طالب بضغطة، و**حضور تعويضي** في أي مجموعة لنفس المادة والصف.
3. **شاشة الباب** (أهم شاشة): بتكتب الكود أو تمسح الـ QR أو تكتب جزء من الاسم أو الموبايل ← **حضور + تنبيه لو عليه فلوس + تحصيل بضغطة**. بتشتغل 100% من غير نت.
4. **التحصيل**: بالحصة، أو بالشهر، أو بالباقة (عدد حصص)، أو محفظة رصيد مدفوعة مقدمًا. طرق الدفع: كاش، فودافون كاش وباقي المحافظ، إنستاباي، فوري. إيصال برقم مسلسل ميتكررش (طباعة حرارية أو PDF أو صورة). وفيه **الملازم والمذكرات** كمخزون، و**خصومات** الأخوات والأيتام والمتفوقين.
5. **الامتحانات والدرجات**: امتحان حصة، أسبوعي، شهري، شامل. رصد سريع، وترتيب الأوائل، و**ربط بشرط الـ 60% تقييمات بتاع الوزارة** (نقول لولي الأمر الطالب جاهز ولا لأ).
6. **بوابة ولي الأمر**: لينك سري خفيف جدًا — حضور، درجات، المدفوع والمتبقي، وترتيبه.

## 3) طبقة التميز (بالترتيب)
1. **الخزنة المحكمة**: كل وردية ليها عهدة، وإقفال يومي فيه **الجرد الفعلي قصاد المحسوب**، والعجز أو الزيادة بيتسجلوا بسببهم، و**سجل مالي ميتمسحش** (تصحيح أي غلطة بيكون بقيد عكسي).
2. **التسوية بين المدرس وصاحب السنتر**: إيجار ثابت للحصة أو للشهر، أو نسبة، أو مختلط (حد أدنى + نسبة)، **وكشف حساب يتطبع** للطرفين.
3. **ربحية كل مجموعة وكل قاعة**: الإيراد − (الإيجار/النسبة + الملازم + المساعدين) ← إشارة (اقفلها / ادمجها / كمّل).
4. **التنبيه بدري إن طالب هيسيب**: نقط خطر من الغياب المتتالي، ونزول الدرجات، والتأخر في الدفع ← قايمة يومية «اتصل بالطلاب دول النهارده».
5. **تواصل مبيقفش**: رسايل جاهزة ← واتساب بضغطة (wa.me من رقم المدرس نفسه، من غير حظر جماعي) + رسايل SMS للحالات المهمة بس + لينك البوابة + **تقرير شهري جاهز** لولي الأمر. واتساب API الرسمي يتضاف كإضافة مدفوعة، بعد ما بقى بفلوس من أكتوبر 2026.
6. **التصحيح بكاميرا الموبايل**: ورقة إجابة (بابل شيت) بنطبعها من البرنامج، والمساعد يصورها ← الدرجة تترصد لوحدها.
7. **مولّد الامتحانات بالذكاء الاصطناعي** على المناهج المصرية والبكالوريا (المدرس بيراجع قبل النشر) + بنك أسئلة.
8. **وضع مجموعات التقوية بالمدرسة**: حد أقصى 25 طالب، وسعر الحصة ≤ 100 ج، وحساب الـ 15% لوزارة المالية وتوزيع الباقي، وكشوف رسمية — **تأمين ضد أي تغيير في القانون**.
9. **أدوات تسويق للمدرس**: صفحة خاصة بيه + لينك حجز + صورة أوائل وشهادات جاهزة للنشر.
10. **حماية الفيديوهات**: علامة مائية متحركة باسم الطالب ورقمه + حد لعدد الأجهزة.

## 4) قواعد التصميم
- عربي من اليمين للشمال بلغة مصرية بسيطة، وأزرار كبيرة، وأي عملية يومية في **3 ضغطات أو أقل**.
- **يشتغل من غير نت أولًا**: كل البيانات محفوظة على الجهاز، وأي عملية بتتسجل في طابور، وبتتزامن أول ما النت يرجع.
- خفيف جدًا: صفحة الباب أقل من 200KB، ويشتغل كويس على أندرويد رخيص ولابتوب قديم.
- استيراد من **إكسل/CSV** مع مطابقة ذكية لأسماء الأعمدة العربية، وتصدير كامل للبيانات في أي وقت.
- الخصوصية: موافقة ولي الأمر، ولينكات البوابة سرية وتقدر تلغيها، ورقم موبايل ولي الأمر مستخبي عن المساعد.

## 5) خريطة الشاشات
الباب ← الطلاب (ملف الطالب) ← المجموعات والجدول ← الحضور ← الفلوس (تحصيل، خزنة، إقفال، مصروفات، ملازم) ← الامتحانات (رصد، أوائل، تصحيح بالكاميرا، مولّد) ← المتابعة (إنذار مبكر، رسايل، تقارير شهرية) ← التسويات والربحية ← الإعدادات (المستخدمين، القاعات، المواد، الأسعار، الاستيراد والتصدير) ← بوابة ولي الأمر.

## 6) التقنيات
- **الواجهة**: React + TypeScript + Vite، كتطبيق ويب يتثبت على الموبايل والكمبيوتر ويشتغل من غير نت (PWA + Service Worker).
- **التخزين على الجهاز**: IndexedDB (عن طريق Dexie) + سجل عمليات (op-log) للمزامنة.
- **السيرفر**: Node.js + Fastify، وقاعدة بيانات SQLite في التطوير وPostgreSQL في التشغيل الفعلي. كل سنتر بياناته منفصلة تمامًا (tenant)، والمزامنة بتمشي بسجل العمليات، والسجلات المالية بتتضاف بس (append-only)، فمفيش تعارضات تضيّع فلوس.
- **الاختبارات**: Vitest لمنطق العمل + Playwright للسيناريوهات اليومية.

## 7) التسعير والبيع
| الباقة | لمين | السعر |
|---|---|---|
| **مجاني للأبد** | لحد 50 طالب نشط | 0 |
| **المدرس** | مدرس لوحده | **2 ج لكل طالب نشط في الشهر** (أقل حاجة 99 ج) |
| **النجم** | مدرس + مساعدين + تصحيح + تسويق | 1.5 ج لكل طالب نشط (أقل حاجة 499) |
| **السنتر** | مدرسين كتير + خزنة + تسويات | 1.25 ج لكل طالب نشط (أقل حاجة 799) |

- **«الطالب النشط»** هو اللي حضر حصة واحدة على الأقل في الشهر ← **مبتدفعش في شهور الركود**. ودي حاجة محدش من المنافسين بيعملها.
- **الدفع الموسمي**: ادفع موسم كامل (يوليو–يونيو) وخد خصم 20%.
- **دخول السوق**: الحملة تبدأ قبل الحجز (مايو–يونيو): نروح للمدرسين النجوم ونقدم «سنة مجانية مقابل إن سنترك يشتغل بالبرنامج» ← السنتر بيشوفه بعينه ← يشترك. ومستورد إكسل مجاني نعمله مع العميل في 10 دقايق.

## 8) ترتيب البناء
- **المرحلة 1 — نواة تتباع**: الطلاب، المجموعات والجدولة، الباب أوفلاين، التحصيل والإيصالات، الخزنة والإقفال، الملازم، الامتحانات والدرجات، بوابة ولي الأمر، الاستيراد والتصدير، الصلاحيات، والبيانات التجريبية.
- **المرحلة 2 — التميز**: التسويات، الربحية، الإنذار المبكر، الرسايل والتقرير الشهري، وضع مجموعات التقوية.
- **المرحلة 3**: التصحيح بالكاميرا، مولّد الامتحانات بالذكاء الاصطناعي، صفحة المدرس وصورة الأوائل، وحماية الفيديوهات.
